Como funciona: 1) resolve o ID exato de cada exchange marcada acima direto na CoinGecko (evita erro de nome); 2) busca todos os pares USDT que cada exchange negocia; 3) usa a lista de moedas da CoinGecko (com endereços de contrato por rede) pra saber em quais das redes marcadas acima cada token existe; 4) mantém só os que têm mcap dentro da faixa definida; 5) para cada combinação exchange + rede em que o token existe, busca o pool DEX mais líquido naquela rede específica e compara o preço — nunca mistura rede errada com exchange errada.

Sobre a checagem de rede: a API pública não revela quais redes de saque cada exchange libera pra cada moeda especificamente (isso fica atrás de login). O que o painel faz é estimar por existência do token: se o token só existe numa única rede (ex: só Solana), a etiqueta fica "rede única" — alta confiança de que é essa a rede de saque. Se o token existe em várias redes (ex: ETH e SOL ao mesmo tempo, como no caso que você viu), a etiqueta fica "confirmar" e a rota fica escondida por padrão (dá pra reativar no filtro acima) — sempre confira manualmente a rede de saque disponível na tela de saque da corretora antes de transferir, mesmo nas marcadas como "rede única".

Limitações: a API pública do CoinGecko tem limite de requisições — quanto mais exchanges e redes marcadas, mais lento e mais chance de erro de limite de taxa (espere um pouco e escaneie de novo se acontecer). Preços de CEX vêm agregados pela CoinGecko, podendo ter pequeno atraso. Este painel só lê preços públicos: não guarda chave de API seleta sua, não acessa sua conta e não executa nenhuma ordem.

Sobre o filtro de idade: a API pública não informa a "data de lançamento" oficial da maioria dos memecoins. O que o painel usa como estimativa é a data de criação do pool de liquidez na DEX (informada pelo DexScreener) — na prática, isso costuma coincidir com o lançamento pra memecoins novos, mas não é garantido (o token pode ter existido antes sem pool, ou ter ganhado um pool novo depois). Trate como indicativo, não como confirmação oficial da idade do projeto.
